1. Quadratic Equations

Quadratic equation ka standard form: ax² + bx + c = 0, jahan a ≠ 0.

D = b² − 4ac
x = (−b ± √D) / 2a

D > 0 → two distinct real roots
D = 0 → equal real roots
D < 0 → real roots nahi hote

📝 Practice

Q1. x² − 5x + 6 = 0 ke roots kya hain?
Answer: 2 aur 3
Q2. x² + 4x + 4 = 0 ka discriminant kya hai?
Answer: D = 0

2. Sequence & Series

AP mein consecutive terms ka difference constant hota hai.

aₙ = a + (n − 1)d
Sₙ = n/2 [2a + (n − 1)d]

📝 Practice

Q1. AP: 2, 5, 8, 11 mein common difference kya hai?
Answer: d = 3
Q2. AP ka first term 3 aur common difference 2 hai. Third term kya hogi?
Answer: 7

3. Trigonometry

Important trigonometric identities ko regularly revise karo.

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ

📝 Practice

Q1. Agar sin²θ = 3/4 ho, to cos²θ kya hoga?
Answer: 1/4
Q2. 1 + tan²θ kis ke equal hota hai?
Answer: sec²θ

4. Differentiation

Differentiation function ke change ki rate ko describe karta hai.

d/dx (xⁿ) = nxⁿ⁻¹
d/dx (sin x) = cos x
d/dx (cos x) = −sin x

📝 Practice

Q1. d/dx (x³) kya hoga?
Answer: 3x²
Q2. d/dx (sin x) kya hoga?
Answer: cos x

5. Integration

Integration differentiation ka reverse process hai.

∫xⁿ dx = xⁿ⁺¹/(n+1) + C
∫cos x dx = sin x + C
∫sin x dx = −cos x + C

📝 Practice

Q1. ∫x² dx kya hoga?
Answer: x³/3 + C
Q2. ∫cos x dx kya hoga?
Answer: sin x + C
