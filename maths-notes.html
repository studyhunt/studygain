1. Quadratic Equations

Quadratic equation ka standard form: ax² + bx + c = 0, jahan a ≠ 0.

📌 Important Formulas

Discriminant: D = b² − 4ac
Roots: x = (−b ± √D) / 2a

📊 Nature of Roots

D > 0: Do distinct real roots.

D = 0: Do equal real roots.

D < 0: Real roots nahi hote.

🎯 Roots ke Relations

α + β = −b/a
αβ = c/a

Yahan α aur β equation ke roots hain.

💡 JEE Tip: Question solve karte waqt equation ko standard form mein lao aur sabse pehle discriminant check karo.

2. Sequence & Series

Sequence numbers ka ordered collection hota hai. Arithmetic Progression (AP) mein consecutive terms ka difference constant hota hai.

📌 AP Formulas

aₙ = a + (n − 1)d
Sₙ = n/2 [2a + (n − 1)d]

Yahan a = first term, d = common difference aur n = number of terms.

📌 GP

Geometric Progression mein consecutive terms ka ratio constant hota hai.

aₙ = arⁿ⁻¹
Sₙ = a(rⁿ − 1)/(r − 1), r ≠ 1
💡 JEE Tip: AP aur GP ke questions mein first term, common difference/ratio aur number of terms ko identify karna important hai.

3. Trigonometry

Trigonometry mein angles aur triangles se related functions aur identities study ki jaati hain.

📌 Basic Identity

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ

📌 Basic Relations

tanθ = sinθ / cosθ
cotθ = cosθ / sinθ

Important angles ke values aur standard identities ko regularly revise karna useful hai.

💡 JEE Tip: Identity prove karte waqt ek side ko simplify karke doosri side ke equal lane ki practice karo.

4. Differentiation

Differentiation function ke change ki rate ko describe karta hai. Calculus mein differentiation ka bahut important role hai.

📌 Basic Formulas

d/dx (xⁿ) = nxⁿ⁻¹
d/dx (sin x) = cos x
d/dx (cos x) = −sin x
d/dx (eˣ) = eˣ
d/dx (ln x) = 1/x

📌 Product Rule

d(uv)/dx = u(dv/dx) + v(du/dx)

📌 Chain Rule

Composite functions ko differentiate karne ke liye chain rule ka use hota hai.

💡 JEE Tip: Basic derivatives ko yaad rakhne ke saath product, quotient aur chain rule ki practice karo.

5. Integration

Integration differentiation ka reverse process hai. Indefinite integration mein constant of integration C add hota hai.

📌 Basic Formulas

∫xⁿ dx = xⁿ⁺¹/(n+1) + C
∫1 dx = x + C
∫cos x dx = sin x + C
∫sin x dx = −cos x + C
∫eˣ dx = eˣ + C

📌 Important Point

Integration questions mein substitution, integration by parts aur standard formulas ka use frequently hota hai.

💡 JEE Tip: Integration ke formulas ko revise karne ke saath unke applications par bhi questions solve karo.
